# Flow Downloader 1.3.1

Bug fixes and quality of life improvements.

---

**Install:** Windows → `FlowDownloader-1.3.1.exe` · macOS 12+ → `FlowDownloader-1.3.1-macOS-AppleSilicon.dmg` (Apple chip) or `FlowDownloader-1.3.1-macOS-Intel.dmg` (Intel) · Linux → `.AppImage`, `.deb` or `.rpm`.
Already using Flow? It will offer the update by itself.
On macOS, if the app is blocked on first launch, right-click it → **Open** (or run `xattr -cr "/Applications/Flow Downloader.app"` in Terminal).
